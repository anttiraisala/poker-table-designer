# CutStudio test files

Seven small EPS files for checking, on a Windows computer with Roland CutStudio, that the EPS export opens correctly.
They are generated by `node scripts/make-cutstudio-tests.js` from the same code as the calibration EPS files
(`js/eps.js`). The export was verified in a real CutStudio on 2026-11-09 (it opens, the size and direction are right, and it prints/cuts correctly); these files stay as a regression check after any change to `js/eps.js`.

## How to test

1. In CutStudio choose **File, Import** and pick a file from this folder (file type: EPS or AI).
2. Check size, shape and direction against the table below. Select the object and read its size in the toolbar.
3. If everything looks right, cut one or two on scrap film.
4. Note what happened (opens or not, size, direction, last line missing or not) and report it.

| File | Expected in CutStudio |
| --- | --- |
| `01-square-50mm.eps` | A square, 50 x 50 mm. |
| `02-circle-50mm.eps` | A circle, 50 mm across (made of 4 curves). |
| `03-triangle-apex-up.eps` | A triangle, 50 mm wide and 50 mm high, the point at the **top**. Upside down means the y axis is wrong. |
| `04-quarter-arc-r50.eps` | An **open** quarter circle of radius 50 mm in a 50 x 50 mm box: the centre of the circle is the top left corner of the box and the arc runs from the top right corner to the bottom left corner, bulging towards the lower right. |
| `05-line-100mm.eps` | One straight line, 100 mm long (the last line must not be skipped: this is the only line in the file). |
| `06-letter-L-orientation.eps` | A letter L, 60 mm wide and 80 mm high: a tall bar on the left and a foot at the **bottom** pointing to the **right**. Mirrored or upside down means the direction is wrong. |
| `07-calibration-strip-horizontal.eps` | The 480 x 20 mm calibration strip: a bar with square marks on top; the left end has a mark with a small foot to its right (it shows which end is left). Measure its length after cutting. |

## What to look for

* Does the file import at all? (CutStudio ignores EPS files it cannot read, sometimes without a message.)
* Are the sizes right (1 pt is 25.4 / 72 mm)? A wrong size means the unit conversion is wrong.
* Is anything missing, especially the last path of a file?
* Are the closed shapes really closed (no gap at the starting point)?
* Do curves look smooth?

The files are lines only: no fills, no groups, no clipping, no text.
